# public/ — assets estáticos servidos en la raíz

Vite sirve todo lo que está aquí en la **raíz del sitio** (no en `/public`).

## Video del Hero

Coloca tu video de fondo aquí como:

```
public/hero-bg.mp4
```

Se consumirá en el código como **`/hero-bg.mp4`** (sin el prefijo `/public`).
Recomendado: H.264/MP4, 1920×1080, 6–12 s en loop, < 4 MB, sin audio.
Opcional: `public/hero-poster.jpg` como imagen de carga (`poster`).

Si el archivo no existe, el Hero muestra automáticamente una **escena SVG de
respaldo** (amanecer en carretera) — la página nunca se rompe.
